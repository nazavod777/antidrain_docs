# Вывод активов с донора {#upravlenie-aktivami-donora}

Вывод активов с донора — это панель на первом шаге, которая помогает управлять активами кошелька-донора.

Обычно он нужен после спасения, чтобы вывести остатки с донора.

## Что можно сделать

В зависимости от сети и доступных активов можно:

- Посмотреть нативный баланс.
- Посмотреть баланс ERC-20.
- Вывести нативную монету.
- Вывести токен ERC-20.

## Как вывести нативный баланс {#kak-vyvesti-native-balance}

1. Откройте рабочую область: `https://antidrain.me/workspace`.
2. Откройте панель Вывод активов с донора на первом шаге.
3. Введите адрес получателя.
4. Нажмите «Вывести».
5. Проверьте текст подтверждения.
6. Подтвердите отправку.

## Как вывести ERC-20

1. Убедитесь, что токен отображается.
2. Введите адрес получателя.
3. Проверьте сумму.
4. Нажмите «Вывести».
5. Подтвердите.

## Важные проверки

Перед выводом проверьте:

- Адрес получателя не совпадает с адресом донора.
- Адрес получателя указан правильно.
- Выбранная сеть правильная.
- У донора хватает газа.
- Токен действительно тот, который вы хотите вывести.

## Почему нельзя отправить

| Причина | Что проверить |
|---------|---------------|
| Баланс нулевой | На доноре нет активов для вывода |
| Неправильный адрес получателя | Введите правильный адрес получателя |
| Адрес получателя совпадает с донором | Нельзя отправить на тот же адрес |
| RPC недоступен | Проверьте подключение и выберите другой RPC |
| chain ID не совпадает | Выбрана неправильная сеть, выберите правильную |
| Не хватает газа | На доноре недостаточно средств на газ |
| Токен не найден | Контракт токена не поддерживается |
